# Skylands Project Brief

## Product

Skylands is an incremental city builder video game about building cities on flying islands across repeated finite runs. It mixes city-builder spatial planning with incremental progression: each run pushes the city farther before SkyCoin failure, while persistent Bonuses bought with DivineCoin make future runs stronger.

The intended tone is heavily meme-inspired light satirical fantasy. Final first-playable Bonus names are intentionally playful: **Stonks !**, **Long Suffering**, and **Drug Traffic**.

## Player

The first player is a solo player who wants addictive short sessions that can grow into longer optimized runs. Early successful runs should last around two minutes and award enough DivineCoin to buy or approach the first Bonus if the player does not end too early. Later runs should commonly last 20-45 minutes, with skilled optimization able to stretch longer, but Escalation must eventually dominate.

## Core Loop

1. Start a run with a fixed SkyCoin amount, a free City Core, and many visible buildable Flying Islands.
2. Place Buildings and Roads on a 3D tile grid.
3. Grow Citizens through housing and Food.
4. Generate Tax Income from Citizens while SkyCoin drains and Escalation increases pressure.
5. Accumulate visible Performance from city growth, active Buildings, and Milestones.
6. End through **I Declare Bankruptcy** when SkyCoin reaches zero or by using **Task Failed Successfully** early.
7. Convert Performance into DivineCoin, buy persistent Bonuses, and start a stronger run.

## First Playable Scope

Included:

- SkyCoin, DivineCoin, Citizens, Food, Tax Income, Productivity, Performance
- City Core, Road, House, Farm, Workshop, Market, Monument
- Three Bonuses: Stonks !, Long Suffering, Drug Traffic
- Milestones and Milestone diminishing returns
- City Screen and between-run Bonus Screen
- Save State for DivineCoin, Bonus levels, Milestone reach counts, and current run

Excluded from the first playable version:

- Jobs
- Ores
- Energy, Knowledge, and Transport as explicit systems
- Offline run progress
- Building Modelizer as a player-facing feature

## Economy

SkyCoin is spent on Buildings and Roads and drains over time. Escalation raises base SkyCoin drain in minute-based steps, becoming exponential in late game. Tax Income is generated by Citizens, scales with Citizen count, and is multiplied by Productivity. Tax Income can exceed SkyCoin drain during parts of a run until Escalation overtakes it.

Food is a capped stock produced per second by Farms and consumed per second by Citizens. If Food reaches zero, new Citizens stop arriving, but existing Citizens still generate Tax Income in v0.

Productivity slightly multiplies produced outputs and contributes to Performance. Market adds Productivity. Workshop produces run-lifetime Performance over time while active. Monument is an expensive late-run SkyCoin sink that adds Performance and can trigger Milestones, but does not help the city survive.

## Buildings And Placement

The City Core is fixed, unique, free, cannot be destroyed, and cannot be upgraded in v0. It starts on a generated starting island in a fixed valid position and provides small baseline Citizen capacity.

Buildings:

- Are placed instantly from a toolbar
- Occupy 2x2 tiles in v0
- Require all footprint tiles to be buildable and at the same height
- Can be placed while disconnected, but remain inactive until connected
- Cannot replace Roads directly
- Can be demolished with no refund
- Have costs that increase by count for each building type, resetting each run

Roads:

- Occupy one tile
- Cannot overlap Buildings
- Can be placed by dragging a path
- Show path validity and total SkyCoin cost before placement
- Reject the whole path if total cost is unaffordable
- Can be demolished with no refund

A Building is active when any tile of its footprint is orthogonally adjacent to a Road connected to the City Core. Disconnected Buildings produce nothing and consume no operational resources.

## World And Camera

Gameplay uses a 3D isometric tile grid. Flying Islands can have height differences and may be procedurally generated for shape and size. All generated island land tiles are buildable.

Empty Tiles exist between Flying Islands. Only Roads can be built on Empty Tiles. Roads on Empty Tiles are Sky Roads and cost more than Island Roads.

Island Roads can connect adjacent island tiles only when their height difference is one level or less. A Ramp Road is an Island Road connecting different heights. Sky Roads can turn like normal Roads and can connect across Empty Tiles only when the landing tile is within one height level of the starting tile.

The City Screen supports pan, zoom, and free camera rotation.

## Runs And Persistence

Simulation advances in one-second ticks, displayed as per-second rates. The player can pause, but paused mode only allows City Screen inspection. Building, demolishing, Bonus Screen access, and Task Failed Successfully require normal speed.

No offline run progress exists. If the game closes during a run, the current run can be saved and resumed, but time does not advance while closed. v0 has one Save State.

## Milestones And DivineCoin

First playable Milestones:

- First House
- 10 Citizens
- First Market
- First Monument
- 100 Performance
- Two-minute survival
- Ten-minute survival

Milestones are one-time per run and contribute to visible Performance. They do not grant immediate rewards in v0. The game persistently tracks how many times each Milestone has been reached. Repeatedly reaching the same Milestone has diminishing DivineCoin value across runs, but visible Performance remains unchanged.

DivineCoin uses a nonlinear prestige formula from Performance. Immediate Task Failed Successfully should award zero unless the city has reached a meaningful Performance threshold. The first successful run should afford Stonks ! if the player does not end too early.

## Input

v0 targets mouse and keyboard first. Mouse is required; keyboard shortcuts are optional polish.

## Development Tooling

The Building Modelizer is a development tool for assembling simple building models cube by cube. It is not part of the first playable game.
